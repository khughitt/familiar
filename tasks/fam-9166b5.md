src/bus/paths.js uses FAMILIAR_STATE_DIR ?? default, so an empty value becomes a cwd-relative state directory, while the Noctalia plugin refuses empty/relative overrides and the desktop popup treats empty as unset. With the variable set but empty the popup reads one attention.json while the CLI it drives writes another. Fail early in core (empty or relative override is a configuration error), consistent with the plugin, and align the popup.
