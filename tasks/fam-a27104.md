The project-colour benchmark baseline at detached 8019302 failed the pre-existing test "a status line invocation makes exactly one cheap git call": the payload uses process.cwd(), so symbolic-ref fails on detached HEAD and the valid rev-parse fallback produces two calls. Use an explicit temporary repository on a known branch for the one-call assertion, preserving real Git and the guard against expensive or extra calls. Cover the detached-HEAD path separately with its expected cheap fallback rather than broadly allowing two calls. Acceptance: the fast suite passes from both named-branch and detached checkouts without weakening the one-call branch assertion; no production statusline behavior changes. This was observed before fam-053b0d closed and is a pre-existing test portability defect, not a regression in project-colour behavior.
