familiar theme add ~/d/familiar-cats fails: '/mnt/ssd/Dropbox/familiar-cats/.worktrees is not a regular file or directory — the source must contain only files and directories'. copySource (src/theme/acquire.js) skips only .git; every checkout under ~/d carries .worktrees as a relative symlink (work-link), and SDD runs add .superpowers/, so no local checkout on this host is a valid source. Docs (install.md) promise 'a clean local theme checkout'; git-clean is not the same as copyable.

Options: (a) skip a fixed set of tool-workspace names beside .git (.worktrees, .superpowers) — small, but the engine learns host conventions; (b) copy only what the pack contract names (theme.yaml, the sprites it references, LICENSE*), so stray entries never reach the defensive copy — recommended, it amends the acquisition contract (spec §3), hence planned. Either keeps refusing symlinks inside what is copied.

Workaround until then: git -C <checkout> archive HEAD | tar -x -C <empty dir>, and add that dir.
