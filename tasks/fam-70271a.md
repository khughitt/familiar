tmux 3.7c: in a pane with x-offset > 0, screen_write_combine() merges a combining character into the grid but the follow-up tty write of the combined cell never happens; at x-offset 0 it does. Repro: printf 'e\xcc\x81' in a right-hand pane shows 'e' until refresh-client/resize. Evidence gathered 2026-09-18 (SIGUSR2 server log): combine at 24,17 in the right pane has no write after it; at 24,9 in a full-width pane it is followed by the tty write. Blocks familiar's placeholders in non-full-width panes (docs/specs/2026-09-18-tmux-rendering-design.md §7.1). Outcome: an upstream issue id recorded here and linked from the docs known-limits entry.
