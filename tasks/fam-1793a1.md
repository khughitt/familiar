Familiar's tracker commits tasks/ records into the same repository that hq's relay cutover merges a pinned feature tip into. Two task-record commits past the pinned PRE blocked the real-host prepare, and hq had to amend its spec to tolerate tasks-only drift (plumbing proofs, pinned merge tree, freeze rules). A linked overlay ([checkout] path in tasks/.config.toml) would keep records out of the code checkout and remove that class of drift for future cutovers.
